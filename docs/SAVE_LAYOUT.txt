Notes
- No header, version or checksum: the file is the raw arrays in this order. Load_Game reads the last block (hero
  names) only when the file is exactly 123,300 bytes (SAVE_FILE_SIZE); otherwise - a save of an older version - it
  clears the names instead, but only 0x221 of the block's 0x230 bytes (a quirk; harmless).
- The unit block holds 9 records past MAX_UNITS (allocated too); why 9 is not known.
- A save slot below 8 also marks the slot as used in MAGIC.SET (struct GameConfig) - see Save_Game.
