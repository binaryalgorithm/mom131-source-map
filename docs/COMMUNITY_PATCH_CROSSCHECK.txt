COMMUNITY PATCH CROSS-CHECK - our numbered bugs vs the community patch files for WIZARDS.EXE
============================================================================================
The community patch is the fans' long-running bug-fix project for Master of Magic 1.31: Insecticide 1.40 (Kyrub),
the Unofficial Patch 1.50 / 1.51 (Seravy), and the Community Patch 1.52 - 1.60 (Seravy and Drake178, released with
Slitherine and shipped with Master of Magic Classic). It is built from numbered patch files, one per change, each
with its authors' own description; the Master of Magic wiki's Community_Patch, Unofficial_Patch_1.50 and Insecticide
pages describe them. All credit for the fixes is theirs.

How this list was made: the byte changes of every patch file in the CP 1.60 'Patches' archive (folders 140 = 1.40
Insecticide IWnnn, 151 / 152 = the 1.5x W-numbered files, Optional) were located in the v1.31 WIZARDS.EXE and mapped
to the functions they change (names and addresses as in the map, index.html). Patch titles are the first line of
each file's own description, shortened. Notes:
- A patch that adds code usually writes it over a function the shipped game never runs (a code cave) - e.g.
  Dev_Choice_Box - so 'changes' can name an unrelated dead function.
- 'written over earlier patch code': most of the bytes the file expects are not the 1.31 bytes, because it changes
  code an earlier patch file wrote; such a file may fix a bug of that earlier patch rather than of 1.31.
- 'our entries' = the BUGS_AND_QUIRKS.txt entries that name the file. For bug-fix files no entry names, our review
  verdict is given where we made one; files with no line are features, balance changes, text changes or not
  reviewed. Only WIZARDS.EXE is covered (not MAGIC.EXE's patch files).
Generated 2026-10-26 by the project's cross-check script.

Part A: 195 of the 491 entries of BUGS_AND_QUIRKS.txt name a community patch file that fixes them (the other 296 name
none - fixed by no patch file we found, or not fixed). Part B: all 777 patch files that change WIZARDS.EXE code,
231 of them cited by our entries.
